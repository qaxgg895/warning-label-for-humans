A program that writes one funny single-line safety warning label for human beings, at most 160 characters, to `/output/entry.txt`: *"WARNING: This human is 70% water, 20% caffeine, and 10% confidently wrong about things it has never googled."* A human as a labelled product — the composition list is real label wording, and the laugh lands in the last few words.

## Run it

```sh
node main.ts
```
